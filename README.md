# Clock Factory

A studio for designing printable clock faces, available in a browser or as a Windows desktop app. The browser editor bundles its geometry libraries and needs no external services at runtime. Development requires Node.js 22.12.0 or newer; Electron and packaging tools are development dependencies for the desktop version.

```sh
npm start
```

Run `npm ci` once to install build tools. The browser development server listens on port 3000 (override with `PORT`). `npm start` and `npm run dev` rebuild the browser script and STL worker before starting. Run `npm ci` before developing the desktop app or running the complete test suite; `npm test` covers geometry, HTTP, and desktop assets.

For static hosting, run `npm ci` followed by `npm run build` and serve `index.html`, `style.css`, `studio.js`, `export-worker.js`, `mesh-view.js`, and `THIRD_PARTY_NOTICES.txt` together. Relative asset URLs support hosting under a subdirectory. After updating, reload the page to load the new browser script. The worker is bundled from `mesh.js`, `mesh-extrusion.js`, `contours.js`, and `export-worker-source.js`; the lazy 3D viewer is bundled from `mesh-view-source.js`. Edit these sources and rebuild rather than editing generated scripts.

STL generation runs in a background worker so the editor stays usable while exporting. You can cancel an in-progress export. Preview, print checks, and download share in-progress builds; cancelling the preview cannot cancel a download using that model. The two most recent meshes and last print file are cached. Color, camera, and display changes reuse geometry. Hosts that block workers use a local fallback.

## Performance

Version 1.14 reuses the source raster, fitted hour positions, painted artwork, and filament analysis. These caches retain only their latest entry and are cleared when the source is replaced, removed, or reset. Geometry checks and STL/Bambu exports skip unused PNG encoding. Native Bambu exports reuse the preview's one-byte filament indices instead of transferring and quantizing four-byte RGBA pixels again. Changing hour contrast refreshes the original 3D texture while retaining the existing GPU mesh. SVG imports encode their large PNGs asynchronously.

The following baseline run and two optimized runs used the same Linux cloud environment, Node.js 24.19, Electron 45.2.1 with software WebGL, and `tests/fixtures/detailed-artwork.svg` at 240 mm with a backing and the A1 quick setup. Optimized times show the range of those two runs. Times vary with hardware and load; the regression tests assert reuse and output correctness rather than timing thresholds.

| Operation | 1.13 | 1.14 |
| --- | ---: | ---: |
| Import SVG and prepare printable colors | 2,787 ms | 2,098–2,591 ms |
| Eleven face-color selections | 708 ms | 108–116 ms |
| Three thickness changes and model checks | 1,210 ms | 916–1,189 ms |
| Open the real 3D preview | 335 ms | 260–440 ms |
| First native color 3MF | 1,633 ms | 686–919 ms |
| Three spool edits and native 3MF exports | 4,685 ms | 1,921–2,411 ms |

Across that workload, full-resolution pixel reads fell from 30 to 3, and exported color-map transfers fell from 40,960,000 to 10,240,000 bytes. The v1.14 production bundles totaled 864,126 bytes instead of 1,152,028 bytes (25% smaller). The final native 3MF was byte-identical before and after: SHA-256 `bb22c3d969bd9712b2aba9852c2d8c86d02af88ecdc1146d2dff7e0883fbcda7`.

Run `npm run test:performance` for the measured workload and checks for source-pixel preservation, refreshed hour textures without geometry rebuilds, lightweight color transfers, and exports that retain their captured SVG during an import. On display-free Linux, build and run `npx electron --no-sandbox --ozone-platform=headless tests/performance.electron.cjs`. Optional `--report=/tmp/performance.json` and `--validation-output=/tmp/clock.3mf` save the measurements and sample print file. `--baseline` records the workload without asserting the new reuse behavior.

Production builds minify all three browser bundles while preserving license notices. Use `node build.js --debug` to generate readable bundles when debugging, then `npm run build` to restore production assets.

## Projects and editing

Drop a single **SVG** or **.clock project** anywhere in the editor, including the preview. A visible drop target shows the file limits. SVGs retain their original colors and details and open the SVG controls automatically; `.clock` files restore the complete saved design. Folders, multiple files, unsupported types and oversized files show a clear message. Dropping a file while a dialog is open asks you to finish that panel first. Invalid files leave the current clock intact; successful imports can be undone.

Under **Upload SVG**, choose **Paste SVG code** to paste source copied from your drawing tool. The panel keeps invalid code editable and shows the error beside it. Use **Ctrl/Cmd+Enter** to import. You can also paste SVG code directly into the main editor with **Ctrl/Cmd+V** while outside a text field. Ordinary text editing keeps normal paste and undo. This uses the clipboard only when you paste; it does not request clipboard-reading permission. Pasted SVGs use the same preparation, sanitizer, saving, print geometry and colors as file imports.

Name your project and use **Save project** to download a portable `.clock` file containing all settings, the original SVG, and its orientation. **Open project** restores it in the browser or Windows app, including on another device. This is an editable project backup, separate from STL/3MF print exports. Imported project files are limited to 12 MB, embedded SVGs to 5 MB. Invalid files leave the current design intact. Restored SVGs pass through the same sanitizer as direct imports, and local-save failures are shown honestly while the project remains usable for the session.

**My projects** keeps up to 20 complete saved copies in this app. Name the copy and choose **Save current design** to retain its original SVG, orientation, dimensions, hours, mechanism fit, desk stand and spool colors. The editor keeps its current name and design; later edits leave the saved copy available. Save another copy after changes. Saving exactly the same named design again reuses its entry. The library shows front-view thumbnails, size, file format, rear accessories and save dates, with search by project or SVG name.

**Open** restores a saved clock through the same validation and SVG preparation as a `.clock` file. Saved copies retain their own SVG source even after it is removed from Recent SVGs. **Backup** downloads the selected saved copy without replacing the current editor. **Remove** deletes a library copy; **Undo removal** restores the last removal until another save or removal. The full library never discards clocks automatically. Library writes update project data and metadata together, and browsing reads thumbnails and metadata instead of loading every SVG. Failed or unavailable device storage leaves the current design usable, with **Backup current design** and a retry available. Copies belong to the current app/browser profile; use `.clock` backups to transfer designs or keep an external copy.

Ctrl/Cmd+Z in the library restores its last removal; text fields retain their normal text undo. Library undo preserves the clock currently open in the editor.

**Find a setting** at the top of the customization panel, or **Ctrl/Cmd+K**, searches size, SVG, hours, movement, stand, colors and print controls. It opens the relevant section, focuses the control and briefly highlights it. For inactive features it takes you to their toggle or prerequisite, with a short explanation. Navigation preserves the design settings. Arrow keys select a result, Enter takes you there, and Esc closes the results. Common French terms such as “chiffres”, “mécanisme” and “dégagement” are also recognized. Ctrl/Cmd+K in My projects focuses its saved-clock search.

Undo/redo stores up to 60 design states, including imported artwork and reset operations. Slider movements are grouped into a single undo step. Use the toolbar, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, or Ctrl+Y; text fields keep their normal text-editing undo. Ctrl/Cmd+S saves a project and Ctrl/Cmd+O opens one. The Windows File and Edit menus offer the same project and history actions. History stays in the current session; the latest design is saved locally and project files provide portable backups. Reset keeps the saved SVG library.

Set the diameter from 100 to 300 mm in 1 mm steps using the slider or exact-size field. **Show hands** controls the illustrative hands in Design view; they never appear in print files. The welcome card can be dismissed, tabs support arrow-key navigation, and the workspace adapts to mobile screens.

Valid size edits apply immediately even while another measurement needs correction. Quick size presets and the diameter slider can also recover an invalid exact-size entry. Downloads stay disabled until all active measurements are valid; the print file uses the same accepted dimensions as the controls.

Center holes accept 5–15 mm in **0.1 mm** steps. Under **Clock mechanism & thickness**, choose **Print a small hole-fit test** to download a compact strip with five through-holes spaced 0.2 mm apart near the current size. The current size is always included, including at the range limits. Raised decimal labels share their geometry with the strip preview, and each opening uses the same analytic contour as the clock's shaft hole. The strip has a 2 mm base and 0.6 mm raised labels; it is one closed piece with a flat back.

Print the strip using the clock's material and slicer settings, try the movement's threaded shaft, then click the matching size to apply it to the clock. This changes the hole and supports undo and project/local restoration. The last prepared strip retains its original sizes for repeat downloads; **New test around…** explicitly prepares another set. The test does not build the full clock or change its design, selected export format, artwork or colors. Downloads are named `clock-factory-fit-test-8.0mm.stl` (with the chosen center value) and support native Windows Save As. Closing or cancelling a pending test stops its worker. A local fallback is available when workers are blocked.

The fit dialog also shows measured model height when a mesh is ready, or a clearly labeled upper bound based on the current settings. Backing, relief, and enabled rear accessories are included. Rear box and stand height contribute to total height but the shaft only passes through the face; the fit controls show that face thickness separately. Leave room for the washer and nut. The diameter-fit strip itself is always 2 mm thick before its raised labels.

**Apply setup** in the print area configures a flat-front A1 clock for a 55 × 55 mm movement: a 5.5 mm raised rear box, 0.5 mm side clearance, 1.6 mm walls, a 3 mm face, 12 fitted Arabic numbers with automatic contrast, and a four-filament A1 / 0.4 mm 3MF. It keeps the original SVG, orientation, diameter, existing backing and spool colors. The existing backing thickness is added to the face. The design change is one undo step; the A1 build plate remains a device preference, as with the existing A1 print choice. **Your mechanism → Edit fit** opens and focuses the mechanism controls directly.

The print review reports unchecked, invalid, ready, and review states for the current design. Actions can add a backing for complete hours or a supported movement box, retain flat artwork in a Bambu color file, fix invalid measurements, fit the printer, or inspect the rear mount. A change to shape clears the checked state until the new mesh is validated. Readiness uses the same geometry cache as preview and export, without starting background mesh builds on every edit. A ready model still needs material and toolpath review in the slicer; disconnected pieces, oversized plates and rear overhangs are reported explicitly.

The print area starts with two choices: **One-color print** prepares an STL, and **Bambu A1 · colors** prepares a native color 3MF and selects the A1's 256 × 256 mm build plate. **More export options** keeps the format, standard textured 3MF alternative, color limit, and back color available without crowding the main workflow. The A1 build-plate preset can also be chosen independently of the file format; custom dimensions stay editable and the selected plate is remembered on this device. An oversized model's **Make it fit** action remains visible while the plate details are collapsed.

**See your print colors** appears when Bambu export is selected. Its front-view color layout uses the same full-resolution artwork raster and color-reduction algorithm as the exporter, before any mesh is built. Compare **Original** and **Print colors**, change the color pickers to match your spools, or **Reset colors** to return to the SVG palette. Identical chosen colors merge into one exported filament, including native painted-facet indices. This is a color layout preview; use Print mesh for relief and shape inspection, and the slicer for toolpath checks. Paint boundaries are approximate at the printer's resolution.

Filament choices leave the original SVG, relief and mesh geometry unchanged, and support undo/redo, local restoration and .clock project backups. They update Bambu exports and the corresponding 3D print-color view; STL and standard textured 3MF keep their existing behavior. Color analysis runs in a debounced background worker with a fallback when workers are unavailable. Recoloring, relief and hole/thickness edits reuse its result; obsolete analyses cannot replace the current layout. Set your real filament/material profiles and AMS assignments in Bambu Studio before slicing. In Print mesh, **Print colors** uses the same reduced palette, chosen spool colors and merged assignments, including the back. **Original** returns to the original SVG texture. These buttons change both color previews. Spool edits replace a cached GPU texture and reuse the existing geometry and color analysis; they do not rebuild the clock. The colors display can still be switched off independently.

**Round backing** joins disconnected SVG letters and shapes on a solid circular plate. Enable it below the SVG appearance controls, or use **Add round backing · join the pieces** after Check model finds separate pieces. The shortcut adds the backing and rechecks the actual mesh. It is optional and off for existing projects. The original SVG is preserved, and backing changes support undo, local restoration and .clock projects.

The plate keeps the selected finished diameter and shaft-hole size. Artwork is uniformly fitted inside its circular border, including its corners; it is not clipped to make it fit. Set the backing thickness from 1 to 10 mm and the border from 1 to 12 mm. Backing thickness is added underneath the original artwork thickness; relief and hour details add their usual height above that. The measured print summary gives the actual total height. Choose a clock movement shaft long enough for the complete face and nut. With **Fit hours to SVG** enabled, complete hours can sit on the backing outside the artwork; supporting material carries each hour up to the front surface. Manual placement retains the earlier clipping to the artwork.

Under **Clock mechanism & thickness**, enable **Rear mechanism mount** and choose **Raised box · walls go up**. It adds an open rectangular box on the back while retaining your selected face thickness. The preset is a 55 × 55 mm body, 5.5 mm box height, 0.5 mm clearance per side, and 1.6 mm walls: a 56 × 56 mm interior and 59.2 × 59.2 mm outside footprint. Width, height, clearance, and wall thickness are independently adjustable. The clock plate forms the floor and the shaft hole stays open; there is no separate lid or fastener. The app rejects boxes without a solid floor beneath them and offers a round backing for unsuitable SVGs.

**Flat front on bed** is on by default for raised boxes. STL and both 3MF exports place the front at Z = 0 and the box walls above the back; a 3 mm face with the default box is 8.5 mm high overall. This mode pauses front relief, texture, and raised hour details so the entire face contacts the bed. SVG colors and complete hour numbers remain on the flat front in color 3MF, with correct lettering and orientation. STL stores the outline and box geometry only. A round backing becomes a uniform face with the combined selected thickness, supported from the first layer. Disabling flat-front mode restores the saved front relief and raised hours; inspect the resulting orientation and supports in your slicer.

**Print mesh → Back** shows the box pointing upward over the bed. **Front** inspects the colored underside and temporarily hides the bed. Project files, undo/redo, local restoration, and print-height estimates include the new box settings. Existing projects saved with a rear pocket retain their recessed geometry until you select Raised box; changing to a box does not reduce a previously chosen face thickness.

Under **Clock mechanism & thickness**, enable **Rear desk stand** to add a fixed support as part of the clock. It works with or without a movement box, and is included in STL and both 3MF formats. The default is 45 mm wide, projects 45 mm behind the rear face, and gives approximately 12° of backward lean. Width and rear depth are adjustable from 25 to 70 mm; lean is adjustable from 6 to 20°. The hollow support has two 3.2 mm ribs and a connecting rear foot. Its walls taper as actual planes, not staircase slices. The app positions the support using the clock’s outline and bottom contact, finds solid attachment material near the bottom, and keeps it clear of the shaft and movement opening. A model-only center-of-mass check blocks configurations outside their desk-contact support polygon; increase depth or width, reduce lean, or add a backing for uneven artwork. These estimates precede real hardware and slicer infill; unsuitable SVGs offer a round backing or dimension adjustments.

A stand always prints with the front flat on the bed, and pauses raised front artwork and hours. Colors and numbers remain available in color 3MF. Your previous front-relief preference returns when the stand is switched off. A 3 mm face with the default stand is 48 mm high as printed; backing adds its selected thickness. The support is one piece with the clock, with no separate download or assembly. Test balance with the real movement and hands fitted; irregular artwork and added hardware can change the center of mass.

Stand placement reserves the movement body even with **Rear mechanism mount** switched off. Earlier versions could place the support inside an unprinted movement on small clocks or short SVGs. **Movement width**, **Movement height**, **Movement depth** and the fit allowance remain available whenever a stand is enabled. Measure the complete movement, including its battery compartment. **Extra space below movement** adds 4 mm by default and accepts 2–20 mm; increase it for access to controls or an off-center shaft. Printed box walls are included in the reserved envelope when a box is enabled. Adjusting movement height or the gap relocates the attachment while retaining the selected rear foot contacts. A design without enough solid space offers a backing or dimension adjustments.

Enabling the stand opens the upright **Desk** inspection automatically. **Show mechanism space** draws a blue outline of the reserved movement and clearance. This is an inspection guide and is absent from STL and both 3MF formats. Width/depth guide changes and hiding the guide reuse the print mesh; movement height and gap changes rebuild the affected stand. The gap supports undo, project backups and reopening; older projects receive the 4 mm default. Re-export older stand files to obtain the corrected placement.

Use **See it standing** or **Print mesh → Desk** to inspect the clock upright at its selected lean, with the foot on the desk surface. The Desk pose changes inspection only; downloads remain front-down for printing. Front/Angle/Back restore the print orientation. Stand settings support undo, project backups, and local restoration, and stay off in older projects. The A1 quick setup preserves an enabled stand and its dimensions.

Choose **Recessed pocket · cuts into the face** to retain the earlier recessed option. The adjustable preset is a 55 × 55 mm body, 5.5 mm depth, and 0.5 mm clearance on each side, making a 56 × 56 mm opening. Width and height are independent; measure your movement before printing. The shaft hole remains separately adjustable. Enabling the pocket increases the face to 7 mm, or an enabled SVG backing to 6.8 mm, when needed to leave at least 1.2 mm of material in front. Existing greater thickness is retained. The pocket also requires at least 1.2 mm of surrounding material and is rejected if it intersects missing artwork. A thick round backing can provide the missing support.

The recessed option removes material without adding height. Use **Print mesh → Back** to inspect its opening and depth; the build plate is hidden for this recessed view. Review orientation, bridging, and supports in the slicer: the recessed back is no longer flat. Pocket dimensions and automatic thickness changes support undo, saved projects, and local restoration.

Design view, real 3D inspection, STL, native Bambu 3MF and standard textured 3MF use the same fitted artwork frame. The Bambu color preview fills transparent gaps with filament 1, which also paints the backing; standard 3MF uses the selected face color for it. Transparent antialiased edges of opaque fills reuse their solid filament color rather than creating an extra blended filament. Distinct translucent fills still composite against the base color.

After exporting, the next steps match the file: Bambu users are told to open it as a project and map filaments, while STL and standard textured 3MF have their own instructions. **Download again** reuses the prepared file. On small screens, a fixed shortcut bar jumps to **Edit design**, **See preview**, or **Download** without changing the design. The help dialog gives a three-step introduction with optional movement and printing details.

## Real 3D preview and print checks

**Design** shows the artwork with optional illustrative hands. **Print mesh** displays the actual validated STL geometry, including shaft opening, thickness, SVG relief, hour details, and an enabled rear mount. Flat-front mode shows the actual flat colored face instead of raised front details. Drag to orbit, scroll/pinch or use the buttons to zoom, and use Front/Angle/Back to inspect the model. The optional edges, build-plate, and SVG-color displays do not alter the exported model. SVG colors use the same embedded texture placement as 3MF. Three.js is bundled locally and loaded only when needed; rendering runs on changes rather than in a continuous animation loop. If 3D graphics are unavailable, design editing, model checks, and downloads remain usable.

**Expand preview** gives Design and Print mesh most of the window, including on a phone. It reuses the existing preview, model and camera; closing it restores editing focus and page position. Narrow 3D views adjust their framing to keep the complete clock visible, while preserving relative zoom. With the preview focused, use the arrow keys to rotate, +/− to zoom, 0 to reset, 1 for Front, 2 for Angle, 3 for Back in Print mesh, and 4 for Desk when a stand is enabled. F expands the preview; Esc or **Back to editing** returns to the workspace. Preview inspection does not change print files.

**Check model** reports the measured X × Y × Z bounds, solid volume in cm³, and number of connected parts. Solid volume describes the model geometry, not an infill-dependent material estimate or print-time estimate. The build-plate settings accept 80–500 mm per side and check both direct and quarter-turn fit. **Make it fit** reduces the diameter with a 2 mm margin per side when possible. The 100 mm minimum still applies. Multiple disconnected SVG pieces are reported, with an optional one-click round backing; connecting geometry is added only when you enable it. Print checks supplement inspection in the printer's slicer.

Choose one of six designs or upload SVG artwork, adjust dimensions and finish, and download a binary STL or a standard 3MF model. SVG colors, strokes, gradients, patterns, lettering, local styles, symbols, clipping, masks, embedded images, and common filters are retained in the preview. Original artwork is the default; its color contrast becomes printable relief instead of disappearing into a flat silhouette. STL units are millimeters. Export traces antialiased contours at approximately 0.15 mm sampling, triangulates flat faces, and uses analytic circular geometry for the shaft opening and ripple rings. Curve simplification is limited to 0.02 mm. A narrow smooth rim keeps surface details clear of outer edges and cutouts; very thin artwork can remain smooth. Preset textures and hour markers add up to 0.8 mm; SVG relief is adjustable from 0 to 2 mm, with added hour details up to 0.8 mm above it. Slicer inspection is recommended, particularly for disconnected uploaded artwork or a rear pocket. Hands and movements are not included; choose a shaft long enough for the remaining face, relief, washer, and nut. Preset settings are stored locally; up to eight recent SVG files are saved locally on the device. No account, API keys, or installation is needed.

## Windows desktop app

The Windows version runs the editor offline in its own desktop window. There are two ways to use it:

- Run `Clock-Factory-1.18.0-Windows-Portable.exe` directly, without installation.
- Run `Clock-Factory-1.18.0-Windows-Setup.exe` to install it, then open **Clock Factory** from the Start menu.

End users do not need Node.js or a development server. SVGs and projects are opened locally; STL, 3MF, and project files are saved on the computer. Download names use the app version, so later versions will have a different version number.

Save feedback distinguishes choosing a location, saving, a completed save, cancellation, and a failed disk write. A completed Windows save shows the actual filename, including a name chosen in Save As. **Try save again** reuses the prepared file after cancellation or failure, even if the design has since changed. This applies to projects, print files, and hole-fit strips. Browser feedback reports that the download started; check the browser's downloads for the destination and final result.

To develop the desktop app, install Node.js 22.12.0 or newer and run:

```sh
npm ci
npm run desktop
```

To create the Windows x64 installer and portable app on Windows after `npm ci`:

```sh
npm run dist:win
npm run dist:win:portable
```

Both downloads are written to `dist/`. They are currently unsigned; signed distribution requires a code-signing certificate.

The **Windows desktop app** GitHub Actions workflow runs on pushes to `main`, version tags such as `v1.5.0`, or a manual run from the repository's Actions tab. It installs locked dependencies, builds the assets, runs the tests, and packages both downloads in the same Windows job. Download the **Clock-Factory-Windows-x64** artifact from the completed run; it contains the installer, portable app, and `SHA256SUMS.txt`. Creating the workflow alone does not start a remote build or publish a release.

SVG imports are fitted to their visible artwork, including drawings with large viewBoxes and transformed groups. Preview and exported geometry share the same footprint and orientation. External resources and executable content are removed; embed linked images and convert text to paths when exact lettering across devices matters. Self-contained artwork is rasterized at 2048 pixels before fitting; printing details finer than the contour sampling or printer resolution is approximate. Imports up to 5 MB are saved locally in an eight-file recent library, and the selected artwork, detail settings, and quarter-turn/mirror orientation are restored on reopening. When local storage is unavailable, the current SVG remains usable for the session and is clearly marked as unsaved.

The imported-artwork card offers **Original artwork + details** and **Silhouette + filament color**. Original artwork replaces the added ripple/crosshatch texture. **Detail relief** controls its height; **0 mm** keeps the face flat. By default, colors that differ from the dominant painted background are raised, so light lettering on a dark badge and dark lines on paper both work. Dark-area and light-area modes offer explicit alternatives. Relief uses up to eight nested steps in one closed solid with a flat back; it does not reproduce color as separate filament parts. Silhouette mode retains the earlier color and texture customization.

Run `npm run test:svg` for desktop SVG import regressions, including visible preview pixels and STL output. Run `npm run test:svg-library` for saved artwork, drag-and-drop, orientation, restart restoration, removal, and storage-error checks. On display-free Linux, run `npm run build` followed by `npx electron --no-sandbox --ozone-platform=headless --disable-gpu tests/svg-import.electron.cjs`.

Mesh regressions check the serialized STL for closed seams, consistent winding, dimensions, volume, smooth outer curves, and shaft fit. Texture and marker layers are clipped together before meshing, without intersecting duplicate solids.

Upload an SVG by choosing a file or dropping it onto the upload area. The imported-artwork card shows its thumbnail, filename, and save status; use the rotate/flip controls to orient the artwork without rotating the hands. Preview and exported STL share the same transform. Choose a saved thumbnail to reuse it, or Remove to delete that local saved SVG. Reset design keeps the recent library.

## Hour numbers and 3MF

Enable hour details and choose Simple ticks, Numbers (1–12), or Roman (I–XII). Number size and distance from the center are adjustable; labels stay upright when imported SVG artwork is rotated or mirrored. The same built-in vector outlines drive the preview and printed relief. A smooth halo around the numbers keeps texture clear of their edges. **Hour contrast** offers light, dark, or automatic ink. Automatic contrast samples the original SVG beneath each fitted label and prefers existing dark/light source inks, helping preserve the AMS color budget. The A1 quick setup enables it. Earlier projects retain light hours, and contrast choices support undo and project backups.

**Fit hours to SVG** is enabled by default for uploaded artwork. It moves each complete hour along the correct clock-hand angle, keeping it inside solid material, clear of the shaft opening, and apart from the other hours. When necessary, it reduces all numbers together, with a minimum 4.2 mm numeral height. The status shows how many of the 12 fit and any size reduction. Narrow or disconnected artwork may have no room for all 12; the app blocks an incomplete export and offers **Use a round backing for all 12 hours**. With a backing, the hours can use the full circular face. Turn fitting off to position hours manually using the size and distance controls. Fitting and pocket settings travel with `.clock` backups and support undo.

Choose STL or 3MF beside the download button. Both contain the same validated geometry in millimeters. **3MF compatibility** distinguishes printable filament assignments from a visual texture. Switching formats or color limits reuses the prepared mesh. The Windows app supports native Save As dialogs for both formats.

**Bambu Studio · A1 / 0.4 mm** is the default 3MF target. It writes an unsliced A1 project with native facet painting and a numbered filament palette, rather than relying on PNG texture support. Large mesh faces receive adaptive paint subdivisions, so internal SVG colors survive even when several colors lie on one flat triangle. The geometry itself is unchanged. The project references the installed A1 0.4 mm, 0.20 mm Standard, and Generic PLA presets; select the actual filament presets and map the numbered colors to your AMS spools before slicing. No temperatures or machine G-code are embedded. The file leaves flushing volumes unset; configure these in Studio for your selected filaments.

A1 with AMS Lite supplies up to four filaments. Choose a maximum of 2 or 4; gradients and excess colors become solid-color regions. The exported palette appears below the controls. By default, the back matches the dominant SVG color to save a filament slot; **Use selected face color** preserves a separate back color within the same limit. Native downloads end in `-bambu-a1.3mf`. Open the file as a project in Bambu Studio so both painting and the palette are loaded, then check printer/material settings and slice. Re-export older texture-only files using this target to obtain filament assignments.

**Standard 3MF · original color texture** retains the earlier generic export. In original SVG mode it embeds the painted artwork as a PNG using the standard 3MF Materials extension, with UV placement matching rotations and mirroring. The back and base edges use the selected face color. Texture support depends on the consumer; it does not assign AMS filaments. STL contains geometry only, so imported details appear through relief.

The Bambu project uses the native `Application` discriminator required by Bambu's importer; `Creator` identifies Clock Factory as the generator. The native paint serialization follows Bambu's public facet-paint format and is independently implemented. Printer, temperature, and machine-code preset files are not bundled in Clock Factory.

Run `npm run test:numerals-3mf` for desktop checks of number styles, size, position, saved settings, matching STL/3MF geometry, color, and a real native 3MF save. On display-free Linux pass the same Electron headless flags used for the SVG suites.

Run `npm run test:svg-details` for original SVG color, gradient, pattern, fine-line, text, filter, and clipping checks, real detailed STL/3MF downloads, maximum relief with added numerals, texture orientation, worker fallback, and saved detail controls.

Run `npm run test:studio` for project round-trips and native downloads, undo/redo and native menus, exact-size validation, genuine rendered 3D pixels, shared preview/export builds, build-plate fit, disconnected-part detection, cancellation during texture loading, mobile layout, and graphics fallback. It also checks real downloads from the quick print choices, file-specific instructions, repeat downloads, saved A1/custom plate settings, and actual shortcut navigation at 320 and 390 pixels.
